# 🚀 AI Crypto Insight Agent

An AI-driven multi-agent system for real-time crypto market analysis using Hermes orchestration and MiniMax API.

## 🔍 Overview

This project is designed to solve the problem of fragmented and slow crypto market analysis. It combines on-chain data, social sentiment, and price signals into actionable insights in real time.

## ⚙️ Architecture

The system uses a multi-agent workflow:

- **Ingestion Agent**
  - Collects on-chain data, token metrics, and social signals

- **Reasoning Agent**
  - Uses MiniMax API for anomaly detection and trend analysis

- **Sentiment Agent**
  - Analyzes social sentiment and hype cycles

- **Summary Agent**
  - Converts raw data into actionable insights

- **Hermes Orchestrator**
  - Coordinates agent workflow and task execution

## 🧠 Tech Stack

- Hermes (Agent Orchestration)
- MiniMax API (LLM reasoning)
- Python
- REST APIs (on-chain + social data)

## 📊 Features

- Real-time market signal detection
- Whale activity tracking
- Risk alert system (rug pull detection)
- Sentiment analysis from social platforms
- Actionable summaries for users

## ⚡ Performance

- Reduces analysis time from hours → seconds
- Detects early-stage trends and anomalies
- Optimized for low token usage
